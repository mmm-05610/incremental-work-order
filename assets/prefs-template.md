# 偏好账（项目级，主树：`docs/implementation/prefs.md`）

调度者**遇到相关决策先查这里**：有偏好就按它做（并在提议里说明"按你的偏好 X 我做了 Y"）；
**没有再问用户**，问完**立刻写下来**，以后不再重复问。偏好可以随时改——改了就更新这里并记一行原因。

每行格式：`偏好项 | 默认 | 说明`。取值写 `ask`（每次都问）也是一种偏好。

| 偏好项 | 默认 | 说明 |
| --- | --- | --- |
| 执行模式 | `dispatch` | `dispatch`（子树 + 独立会话，主流）/ `solo`（主树自己实现，可自行开子代理，不建树）。solo 仍保留单、账、门与终态码纪律 |
| 角色组合 | `executor only` | 需要审阅者 / 验收轮询者 / 复用侦察者 / 记录者时，由**调度者提议**、用户批准后加（见 `references/roles-and-loops.md`）；新角色先给最小写权 |
| 开新工作树 | `ask` | 只能由用户批（不可豁免） |
| 合并回主树 | `ask` | 只能由用户批（不可豁免） |
| 放宽验收 | `ask` | 只能由用户批（不可豁免）；**收紧不需要问** |
| 插队（新单排到当前批次之前） | `ask` | 不打断正在跑的那张单 |
| 改向（撤回在跑的方向） | `ask` | 必须留修订记录与回执 |
| 批次大小 | `3-4 张单` | 小改动允许 1 张单 1 个阶段 |
| 检查点节奏 | `批末` | `批末` / `每单` / `每 N 单`；检查点只打 tag + 写报告，**不为它停下** |
| 验收严格度 | `strict` | strict = 每门必须有反例与"缺席即失败"；放宽要用户批 |
| 证据落点 | `evidence/<NNN>-<slug>/` | 小项目可内联进本树 status（在偏好里写明） |
| 执行者侧子代理并行 | `允许；上限 4；仅限声明的独立单元` | 与项目 AGENTS.md 的子代理限额叠加，取更严者；不允许并行写更省心 |
| 成本上限 | `<未设>` | 单批次/单项目的请求数或金额上限；超了先停下问 |
| 通知范围 | `只通知受影响的树` | 不群发 |
| 交付提示词 | `内联全文` | 一切要用户复制的内容在回复里给全，不做文件指针 |
| 语言 | `中文` | 文档与报告语言 |
| 归档 | `收口即归档` | 单收口后移入 `work-orders/archive/<YYYY-MM-DD>-NNN-slug.md` |
| 每单费用/请求数 | `记` | 写进汇总账的"请求数与费用"列 |

## 豁免（waive）

调度者可以偏离上面任何**可豁免**项，但必须在被偏离处写明理由：
- 单级：工单 frontmatter 的 `waive: ["小节: 理由"]`
- 项目级：`rulings.md` 记一条（`R-xxxx`），并在提议里说明
- **不可豁免**：凭据与受保护路径规则、不 push / 不自动合并主干、开树 / 合并 / 扩权 / 放宽验收要用户批、
  执行者不替用户做产品裁决。
